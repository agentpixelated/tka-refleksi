# No. 39 — Akar berlawanan tanda: jumlah akarnya nol (Vieta)

**Soal (L1-No.5).** Jika akar-akar persamaan (x² + ax)/(m + 2) = (bx − 2)/(m − 2) berlawanan tanda (angkanya sama) dan a ≠ b, maka nilai m adalah …

A. (a+b)/(a−b) **B. 2(a+b)/(a−b)** C. a+b D. 2(b+a)/(b−a) E. (b+a)/(b−a)

*Sumber: Try Out TKA 001 2026/2027*

---

## Dasarnya

**Rumus Vieta** untuk ax² + bx + c = 0: jumlah akar-akar = **−b/a**, hasil kali akar-akar = **c/a**.

Akar "berlawanan tanda (angkanya sama)" artinya akarnya r dan −r. Jumlahnya: r + (−r) = **0**. Jadi syaratnya satu kalimat: **koefisien x harus nol** (karena jumlah akar = −(koefisien x)/(koefisien x²) = 0).

Strategi umumnya: (1) rapikan persamaan jadi bentuk kuadrat baku, (2) paksa koefisien x = 0, (3) selesaikan untuk parameter yang ditanya.

## Aplikasinya

Langkah 1 — kali silang:

(m − 2)(x² + ax) = (m + 2)(bx − 2)
(m − 2)x² + a(m − 2)x = b(m + 2)x − 2(m + 2)
**(m − 2)x² + [a(m − 2) − b(m + 2)]x + 2(m + 2) = 0**

Langkah 2 — jumlah akar = 0, jadi koefisien x = 0:

a(m − 2) − b(m + 2) = 0 → a(m − 2) = b(m + 2)

Langkah 3 — selesaikan untuk m:

am − 2a = bm + 2b → m(a − b) = 2(a + b) → **m = 2(a + b)/(a − b)**

(Syarat a ≠ b menjamin penyebut tak nol — memang diberikan di soal.)

**Kunci: B** — m = 2(a+b)/(a−b).
