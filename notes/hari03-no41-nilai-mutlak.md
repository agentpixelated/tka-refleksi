# No. 41 — Nilai mutlak: pecah kasus di titik nolnya

**Soal (L1-No.18).** Banyaknya bilangan real x yang memenuhi |x² − 4| = x + |x − 2| adalah …

A. 0 B. 1 C. 2 D. 3 E. 4

*Sumber: Try Out TKA 001*

---

## Dasarnya

Persamaan nilai mutlak diselesaikan dengan **memecah kasus** di setiap titik di mana isi mutlak = 0. Di sini: x² − 4 = 0 → x = ±2; dan x − 2 = 0 → x = 2. Titik-titik kritis: **−2 dan 2**, membagi garis bilangan jadi tiga daerah: x < −2, −2 ≤ x < 2, x ≥ 2.

Di tiap daerah, buka mutlaknya (positif tetap, negatif dinegasi), selesaikan, lalu **cek apakah solusi masuk daerahnya** — yang di luar daerah dibuang.

## Aplikasinya

**Daerah x ≥ 2:** |x²−4| = x²−4, |x−2| = x−2.
x² − 4 = x + (x − 2) → x² − 2x − 2 = 0 → x = 1 ± √3.
Yang ≥ 2: 1 + √3 ≈ 2,73 ✓. (1 − √3 ditolak.)

**Daerah −2 ≤ x < 2:** |x²−4| = 4−x², |x−2| = 2−x.
4 − x² = x + (2 − x) → 4 − x² = 2 → x² = 2 → x = ±√2.
Keduanya di [−2, 2): √2 ≈ 1,41 ✓, −√2 ≈ −1,41 ✓.

**Daerah x < −2:** |x²−4| = x²−4, |x−2| = 2−x.
x² − 4 = x + (2 − x) → x² = 6 → x = ±√6.
Yang < −2: −√6 ≈ −2,45 ✓. (+√6 ditolak.)

Total: (1+√3), √2, −√2, −√6 → **4 solusi**.

**Kunci: E** — 4.
